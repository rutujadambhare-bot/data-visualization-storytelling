# Data Visualization and Storytelling

## Internship Task

This project presents a visual data story using the Sample Superstore dataset.

## Business Question

Why is strong sales growth not translating into equally strong profit?

## Tools Used

- Power BI
- Tableau
- Microsoft PowerPoint
- Data Visualization

## Key Insights

- Sales increased significantly between 2019 and 2022.
- Furniture generated high sales but comparatively low profit.
- Higher discount levels were associated with weaker profit margins.
- Some sub-categories contributed strongly to profit while others created losses.

## Recommendations

1. Reduce blanket discounting.
2. Review pricing and costs for loss-making products.
3. Focus sales and marketing on profitable categories and sub-categories.

## Deliverables

- PDF visual story
- PowerPoint presentation
